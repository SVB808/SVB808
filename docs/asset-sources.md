# Profile assets and factual sources

The SVG artwork is editable and stored in this repository. Regenerate it with `python3 scripts/build_assets.py`.

- **Profile header:** original vector artwork. Only the small signal path animates. A static alternative and a reduced-motion media rule are provided.
- **Technology icons:** [Devicon](https://github.com/devicons/devicon), embedded in original frames. The MIT license is retained at `assets/vendor/devicon/LICENSE.txt`. Original input SVGs are preserved in that directory.
- **ChangeGuard:** architecture illustration, not a product screenshot or terminal output. Based on the [project README](https://github.com/SVB808/changeguard/blob/6fe77d50ea820e88c3b7e66fee5a0da48104434f/README.md). The project is a release candidate.
- **API workflow benchmark:** chart redrawn from [published results](https://github.com/SVB808/openai-decisions-api-benchmark/blob/c755b05e7812f3df4194b9a112f747c1f198f58d/extended_report.md). Bars use the actual median values (126.84 ms and 1468.97 ms) on the same linear scale. The run used 200 calls per workflow over 40 scenarios paraphrased five ways. It is exploratory and compares workflows with different output contracts; it does not establish universal API performance.
- **Desktop focus companion:** architecture illustration, not a screenshot. Based on the [project source](https://github.com/SVB808/flowpet-desktop/tree/8a983afd5f9a2a7bb946c3ef4b49dfeae11c6bd2). Native tracking, classification, and local SQLite history connect to a React/Tauri companion. The repository's FlowPet name remains a working title. This profile does not imply a signed or production-ready release.
- **Open-source activity:** [Hiero Java SDK PR #3042](https://github.com/hiero-ledger/hiero-sdk-java/pull/3042) is merged. It corrects Javadoc references, not runtime behavior. Its description records Javadoc generation and targeted tests.
- **Contact:** LinkedIn and email match the account owner's supplied résumé. No phone number, private repository source, or résumé file is published here.

All images load from this repository. There are no third-party statistics image services, scheduled workflows, visitor trackers, JavaScript assets, or access-token requirements.
